# KidZooKit SEO proposals

Source: live pages fetched 2026-10-18. Proposed text uses only content already on those pages. Suggestions only; nothing on the site was changed.

## Pattern guide

- **Title** (about 50-65 chars): `<Topic> for Kids: <what you get> | KidZooKit`. Lead with the search phrase (animal or place name + 'for Kids'). Current titles end with ` · KidZooKit`; pick one separator and use it sitewide.
- **Meta description** (about 120-160 chars): one sentence with the topic, 2-3 concrete things on the page (cards, talk prompts, live cams, printable hunt), then 'Free' or 'no signup'. Never empty.
- **H1**: exactly one per page, same words as the title's topic, plain text. Emoji can stay as decoration but put the keyword phrase in text (e.g. 'Puffin Animal Card for Kids').
- **Intro** (2-3 sentences, visible right under the H1): sentence 1 says what the page is; sentence 2 reuses facts already on the page (quick tips, stop lists, listed animals); sentence 3 says what to do (try the quiz, print the card, print a hunt).
- **Animal cards**: `<Animal> for Kids: Animal Card, Quiz & Talk Prompts`. **Place pages**: keep 'Explore at Home or Print a Hunt', shortened. **Hubs** (zoos, parks, aquariums): name 3-4 example places.
- Fact policy: no new animal facts. Intros reuse each page's own quick tips and stop lists.
- After shipping: confirm one H1 per page, canonical unchanged, then request indexing in Search Console for the top pages.
